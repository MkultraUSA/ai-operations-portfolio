### Post 2: The Problem

Goal: make the pain obvious and relatable.

Asset: before/after workflow diagram.

Draft:

```text
One underrated AI operations problem:

The work does not fail because the model is useless. It fails because the operating context is scattered.

A project might involve:

- one chat for planning
- another task for coding
- a remote server
- a GitHub repo
- a notes folder
- a scheduler
- a human interruption

Without a handoff system, the next session starts by guessing.

Context Forge is my attempt to solve that at the workflow level. Each work session can retrieve scoped project memory, continue from recorded decisions, and leave behind a structured handoff with verification and next actions.

The point is simple: make AI-assisted work resumable.
```

### Post 4: Architecture

Goal: show systems thinking.

Asset: architecture diagram.

Draft:

```text
The Context Forge architecture is intentionally boring in a useful way.

Codex retrieves scoped project context through a local Context Forge MCP path. The project memory lives in a human-readable vault. A synced filesystem path makes that state available to other environments, including a remote Hermes validation path.

The safety rule is important: project memory is not credential storage and it is not production authorization.

The system is designed around operational continuity:

- retrieve context before work
- do the work
- verify what changed
- write a structured handoff
- let the next task resume from evidence

That is the portfolio story I’m building around.
```

## Screenshot Rules For LinkedIn

- Redact before posting.
- Use captions that say what the image proves.
- Prefer one proof point per image.
- Avoid screenshots full of tiny text unless paired with a zoomed crop.
- Do not post private hostnames, keys, tokens, precise locations, or personal data.
- Assume most hiring managers will not click a link from the feed. Make the post understandable without leaving LinkedIn.
- Put deeper links in Featured, the profile, resume, and replies to people who ask.
