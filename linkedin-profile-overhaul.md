# LinkedIn Profile Overhaul

## Strategy

LinkedIn should be the main public surface. The portfolio and resume support it.

The profile should make three things clear:

1. You build practical AI operations and automation systems.
2. Context Forge is the flagship proof.
3. Your work is inspectable through screenshots, diagrams, sanitized journals, GitHub history, and before/after examples.

## Profile Headline

Use this as the default:

**AI Operations & Automation | Systems Integration | Technical Operations | Building practical AI-assisted workflows**

Alternate:

**AI Automation and Technical Operations | Context Forge, workflow continuity, systems integration**

## About Section

I build practical systems that make AI-assisted work easier to operate, inspect, and resume.

My current portfolio is centered on Context Forge, a project-memory and handoff system for AI-assisted work across chats, models, machines, repositories, remote servers, and interruptions. The goal is not to claim that AI remembers everything. The goal is to create human-readable project memory, evidence-backed handoffs, and safer workflows that another person or agent can inspect.

The strongest proof is the workflow:

- retrieve scoped project context before work starts
- continue from recorded decisions and verification
- avoid storing credentials or treating memory as authorization
- write a structured handoff after substantive work
- let a future task, model, machine, or person resume from evidence

Supporting projects include Battle Buddy, an AI-assisted public-safety/radio operations pipeline, and an infrastructure/home automation lab focused on monitoring, remote access, dashboards, synced notes, and repeatable recovery.

I am targeting roles in AI automation, AI operations, systems integration, technical operations, internal tooling, and applied AI workflow support.

## Featured Section

LinkedIn Pro gives you more visibility, but the profile still needs strong proof assets. Add these items to the Featured section in this order:

1. **Context Forge case study**
   - Link to portfolio page or GitHub Pages page
   - Thumbnail: architecture diagram or screenshot of context retrieval

2. **Context Forge GitHub repository**
   - Link to public repo after cleanup
   - Caption: "Project-scoped memory and evidence-backed handoffs for AI-assisted work."

3. **Sanitized Context Forge handoff**
   - PDF, image, or portfolio page section
   - Caption: "What changed, what was verified, and what the next task should do."

4. **Battle Buddy case study**
   - Link to page or sanitized proof gallery
   - Caption: "AI-assisted capture, transcription, enrichment, and review workflow."

5. **Resume**
   - PDF resume with clickable proof links
   - Caption: "AI operations, systems integration, and technical operations resume."

## Experience Section Rewrite Pattern

For each relevant role or project, use this structure:

**Role / Project Name**

Built and operated practical automation systems across local machines, remote hosts, AI-assisted workflows, synced documentation, and operational dashboards.

Selected proof:
- Built [specific system]
- Connected [tools/services]
- Documented [handoff/runbook/recovery workflow]
- Verified [test/result/outcome]
- Produced [screenshot/repo/diagram/journal]

Keep bullets grounded in artifacts. Avoid soft claims like "passionate about AI."
